# Phone App Builder

A phone-first app builder. Black canvas, full-screen interactive preview, swipe-in side panel.

## Use it
- Open the GitHub Pages link for this repo in Chrome on your phone.
- Swipe right from the left edge (or tap the small tab) to open the side panel. Swipe left on the panel to close it.
- Tap Edit/Play (top right) to switch between moving things and using them.
- Type a description such as: big red button called Start opens screen 2
- Drag elements to move them. Set label, color, size and tap action in the panel.
- Save keeps the project in this browser. Export downloads the project as JSON.

## v0.1 includes
Canvas, edge-swipe panel, drag to move, text-to-button (simple parser, no AI), multiple screens, tap actions (message, go to screen, vibrate), undo, save, export.

## Not built yet

No keys or accounts are stored in this project.
